# mvstudio 요구사항 명세 v1.0

"곡·가사에 맞는 뮤직비디오를 로컬에서 생성한다"를 측정 가능한 기준으로 정의한다.
각 항목은 **수용 기준(AC)**과 **검증 상태**를 갖는다.
상태: ✅ 자동테스트 │ 🖥️ 맥 실기 확인 │ ⏳ 실사용 검증 대기 │ 📋 계획

## R1. 입력
- 오디오: mp3 / m4a / wav / flac. 이미지: jpg / png / webp / heic(아이폰). 가사: .lrc (선택)
- AC: 지원 포맷 입력 시 오류 없이 파이프라인 완주 — ✅(mp3/wav/heic) ⏳(m4a/flac 실사용)

## R2. 음악 분석
- BPM, 비트 그리드, 에너지 곡선, 구간 분리(최소 2개, low/mid/high 라벨)
- AC: 4/4 대중음악에서 BPM 오차 ±5% 이내, 구간 경계는 비트 위에 위치 — ✅(합성곡) ⏳(실곡)

## R3. 비트싱크 컷 편집
- 모든 컷 경계는 비트 그리드에 스냅(±20ms)
- 컷 길이 = 구간 에너지 반영: high 1~2비트, mid 4비트, low 8비트 (±변주)
- 같은 이미지 연속 컷 금지
- AC: 스토리보드 검증기가 위반 시 거부 — ✅

## R4. 이미지 선택 ("곡에 맞는 영상"의 핵심)
- **semantic 모드(기본, Ollama 필요)**: 로컬 VLM이 사진 내용 파악 → 곡 분위기·가사와
  무관한 사진은 **영상에 0장 포함**, 제외 목록을 사용자에게 보고. 관련 사진을
  해당 가사/에너지 구간에 배정
- energy 모드(폴백): 밝기·채도 ↔ 구간 에너지 매칭
- AC: 제외 판정된 이미지가 최종 영상에 등장하지 않음 — ✅(로직) ⏳(실사진+VLM, 맥)
- AC: Ollama 미가동 시 안내 후 energy 폴백, 오류 아님 — ✅

## R5. 카메라 모션
- 컷마다 프리셋(줌/팬/틸트/켄번즈 12종) 적용, 지터 없음(3× 수퍼샘플링)
- 프리셋은 코드가 아닌 데이터(JSON) — 추가·수정에 코드 변경 불필요 — ✅

## R6. 가사 자막
- LRC 타이밍 기준 ±0.2s 내 표시/소멸, 하단 1/3 중앙, 외곽선으로 가독성 확보
- 한글 폰트 자동 감지(macOS AppleSDGothicNeo 등), 어떤 FFmpeg 빌드에서도 동작
- AC: 자막 유무 렌더의 픽셀 차이 검증 — ✅ │ 한글 실렌더 — ⏳(맥)

## R7. 그레이딩·트랜지션
- 구간 라벨별 컬러 그레이드(low=차분/high=진하게, 데이터 정의), 구간 경계 0.15s 딥,
  시작/끝 0.6s 페이드 — ✅

## R8. 출력
- H.264 mp4 + AAC, 영상 길이 = 곡 길이 ±0.1s, 맥에서 하드웨어 인코딩(videotoolbox)
- AC: ffprobe 길이 검증 — ✅ │ videotoolbox 자동 선택 — 🖥️

## R9. 재현성·편집성
- 동일 입력+시드 → 동일 스토리보드(바이트 단위) — ✅
- 스토리보드 JSON 수동 수정 → `mvstudio render`로 결정적 재렌더 — ✅

## R10. 성능
- 4분 곡 + 사진 20장 + 720p, Apple Silicon에서 **5분 이내** (AI 생성 기능 제외)
- 상태: ⏳(맥 실측; 참고로 8초 셀프테스트는 실기에서 수 초)

## R11. 프라이버시
- 곡·사진·가사가 네트워크로 전송되지 않음 (모델 다운로드 제외). 외부 API 의존 0 — ✅(코드 검토)

## R12. 라이선스 (상용 배포 전제)
- 허용: MIT / BSD / ISC / Apache-2.0 (+FFmpeg LGPL 조건부). GPL·비상용(NC) 컴포넌트 금지
- 세부: docs/DESIGN.md 라이선스 매트릭스 — ✅(전 의존성 검토 완료)

## R13. 오류 처리
- 사용자 실수(파일 없음, 빈 폴더, 미지원 포맷, 모델 미설치)에 트레이스백 금지 —
  원인+조치를 담은 1줄 메시지 — ✅ 🖥️

## R14. 설치·사용성
- 설치/업데이트 = `bash setup-mac.sh` 1회 실행(멱등). 이후 어느 터미널에서든
  venv 없이 `mvstudio` 사용 가능. 자가 진단 = `mvstudio doctor` — ✅ 🖥️
- 데모 = `mvstudio demo` 한 줄로 전 기능 쇼케이스 영상 생성 — ✅

## R15. 립싱크 합성
- 외부 도구(ComfyUI 립싱크 노드 등)가 만든 말하는-얼굴 클립을 지정 구간에
  **연속(비트 컷으로 끊기지 않게)** 합성. 구간 오디오 추출 제공(입모양=노래 일치)
- AC: 클립 배치 후에도 타임라인 연속성·곡 길이 불변 — ✅ │ 실제 립싱크 클립으로 최종 검증 — ⏳(맥+ComfyUI)
- 립싱크 생성 모델 자체는 범위 외(외부 도구 위임). 개인용 권장: Sonic·LatentSync,
  상용 배포 시 Apache 라이선스(LatentSync/SadTalker)만
